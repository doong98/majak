# majak (사천성 마작)

웹 브라우저에서 즐길 수 있는 사천성 마작(타일 매칭) 퍼즐 게임입니다.

## 주요 기능
- 전통 마작 패(만수패, 통수패, 삭수패, 자패 등)를 활용한 짝 맞추기
- 2번 이하로 꺾어 연결 가능한 패 선택 규칙 (2회 이하 절선)
- 힌트 및 패 다시 섞기(셔플) 기능
- 점수, 콤보 및 타이머 시스템
- 반응형 웹 디자인 및 경쾌한 효과 연출

## 기술 스택
- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React
- **Effects**: canvas-confetti

## 실행 방법

### 패키지 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 빌드
```bash
npm run build
```
